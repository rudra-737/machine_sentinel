# Three Strong Final-Year Engineering Portfolio Projects

## 1. Machine Sentinel — Predictive Maintenance & Fault Detection Platform
**Best for:** Computer, IT, Electronics, Electrical, Mechanical, Mechatronics, AI/ML.

Build a platform that ingests machine sensor readings such as temperature, vibration, current, RPM and pressure, calculates a health/risk score, detects anomalies, and raises maintenance alerts before a failure occurs.

### Why it stands out
- Combines software engineering, APIs, databases, analytics and engineering-domain logic.
- Easy to demo with simulated or real sensor data.
- Has clear scope for ML, IoT, cloud deployment and dashboards.
- Interview-friendly because you can explain measurable business value: less downtime and earlier fault detection.

### Advanced extensions
MQTT ingestion, ESP32 sensors, Isolation Forest/LSTM anomaly detection, Remaining Useful Life prediction, Grafana, Kafka, TimescaleDB and cloud deployment.

---

## 2. GridWise — Smart Campus Energy Monitoring & Optimization
**Best for:** Electrical, Electronics, IoT, Computer, Energy Engineering.

Create a system that tracks electricity consumption by building/lab/device, forecasts short-term demand, detects abnormal energy usage and recommends peak-load reduction actions.

### Core features
- Smart-meter data ingestion
- Daily/weekly consumption dashboard
- Peak-demand alerts
- Forecasting
- Carbon-emission estimation
- Energy-saving recommendations

### Why it stands out
It connects engineering with sustainability and can be demonstrated using synthetic smart-meter data even without physical hardware.

---

## 3. VisionInspect — AI Visual Defect Detection for Manufacturing
**Best for:** AI/ML, Computer, Mechanical, Production, Manufacturing, Electronics.

Build a computer-vision system that classifies or localizes surface defects in manufactured parts from images and stores inspection results for traceability.

### Core features
- Image upload/API
- Defect classification
- Confidence score
- Inspection history
- Batch-level quality analytics
- Grad-CAM/explainability

### Why it stands out
It demonstrates applied AI rather than only model training. A complete system includes data handling, inference APIs, database design, dashboards and deployment.
